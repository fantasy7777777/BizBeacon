# Roadmap and validation plan

**Status:** Proposed sequence; dates and targets to be set after discovery

## Phase 0: Discovery

**Questions:** Who is the primary user? What task are they trying to complete? Which employer facts matter? Can useful information be sourced and maintained responsibly?

Activities:

- Interview job seekers, students/career changers, and local ecosystem users.
- Test a clickable or paper directory concept.
- Compare likely source types and assess coverage, permitted use, and update effort.
- Select a manageable pilot set across a few Perth industries.

**Gate:** Proceed when a specific user task, initial employer slice, and feasible data process are identified.

## Phase 1: Concierge pilot

- Build a small, manually verified dataset.
- Share a basic directory/profile prototype with target users.
- Observe search, profile comparison, source trust, and apply-link use.
- Record stale or missing data and time required to maintain records.

**Gate:** Proceed when users complete the intended task and the data can be maintained at acceptable effort.

## Phase 2: MVP

- Implement directory search and filters.
- Implement company profiles and job link presentation.
- Add source, verification, and correction workflows.
- Add basic operational monitoring and privacy-conscious measurement.

**Gate:** Publicly broaden access after link reliability, editorial ownership, and support path are ready.

## Phase 3: Improve

Potential additions, prioritized by evidence:

- Saved companies or searches.
- Email or in-product alerts.
- More complete Perth industry coverage.
- Hiring summaries and historical trends once data continuity is sufficient.
- Employer-submitted corrections or profile claims with review.

## Phase 4: Regional expansion decision

Assess user demand, source availability, update costs, support capacity, and the quality of Perth operations. Expansion should reuse region-aware records and workflows, while making each region's actual coverage visible.

## Validation hypotheses

| Hypothesis | Evidence to collect |
|---|---|
| Users want to browse employers as well as jobs | Interviews, task tests, directory usage, and repeat visits. |
| Company profiles make employer research easier | Users can compare employers and explain which facts helped. |
| Apply links are valuable | Profile-to-apply click-through and user feedback. |
| A focused local dataset is useful | Users find relevant employers despite intentionally limited coverage. |
| Data can be kept fresh affordably | Editor time per record, link failure rate, and stale-job rate. |

## Review cadence

Review the roadmap after the discovery and pilot gates. Record decisions in [the documentation index](README.md), including the evidence and unresolved tradeoffs. Avoid setting dates before scope, contributors, and data dependencies are known.
